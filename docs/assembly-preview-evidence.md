# 装配步骤与零件分解预览依据

核对日期：2026-10-26。本页记录第二期已实现部分及未通过的精确定位门槛。

## 范围

- S3 1F 标准旋钮单抽屉：可有网格顶盖、标签、0–4 个连接扣；不包含隐藏旋钮、齿条、分隔和改装配件。
- S3 2F 标准整盖翻盖箱：可有标签；不包含分隔和改装配件。
- 其他配置返回明确的不支持状态，不会用入门示例代替用户的选型。
- 装配页说明一套产品；配置页的套数、打印计划和组合坐标不会被改写。

## 手册与文件映射

完整视觉核对 `02_Drawer Assembly.pdf` 的 8 页和 `03_Sustainers Assembly.pdf` 的 7 页。

抽屉流程：旋钮与盖（1）、弹簧（2）、清理内抽支撑（3）、内滑轨（4）、面板/孔盖/标签（6，标签文字见5）、外导轨与外壳（7）、限位块及连接扣（8）。可选网格顶盖仅引用总说明第10页的选型资料，不虚构安装轨迹。

翻盖箱流程：锁与销（1）、锁座固定面板（2）、上下铰链（3）、顶盖连接和轴（4）、面板及标签（5）、支撑和机构检查（6）。手册中的宽箱示例有两个锁，S3 用一套。第7页分隔片不属于当前示例。

步骤里的打印文件 ID 从当前配方反查，完整覆盖所选文件。锁销和弹簧等组合文件不按几何物体数重复乘份数。面板孔盖和限位块各两份，三维视图也显示两份整份文件。

五金按既有配方及其核对状态呈现。S3 翻盖箱 M4×14 共8颗拆为锁座4、上铰链4；下铰链 M4×10 共8；前面板 M4×20 共4仍标参考及孔位核对。步骤数量求和测试与整套五金完全一致。

## 为什么未开放整套精确合拢

本地 STL 使用独立打印摆放坐标，不能直接叠加：

| 文件 | 最小坐标 mm | 最大坐标 mm |
| --- | --- | --- |
| S3 Module 1F | 8919.15, 722.38, 1125.00 | 9083.96, 779.39, 1271.10 |
| S3 Box 1F | 8934.46, 1710.54, 5.00 | 9068.65, 1854.34, 42.50 |
| S3 Grid Roof | 7788.05, 3252.49, 1226.93 | 7911.74, 3376.17, 1372.90 |

顶盖有额外旋转，成对滑轨/弹簧/铰链与多根销轴还需要拆分后独立定位。手册是图示，没有给出局部装配基准及数值变换。整套接合变换尚未建立。标准旋钮与盖、S1F前面板与旋钮三件组已有独立数字定位，详见[两件记录](key-cap-joint-evidence.md)与[三件记录](panel-joint-evidence.md)。

因此整套的 `precision_ready` 固定为 false；已核对子装配通过 `joints` 返回，`joint` 保留旧两件描述。整套分解视图仅做文件整体居中、Z向上到屏幕Y向上的坐标转换和分开展示，保持所有文件一致的毫米比例。零件列表以整个打印文件为单位；只有弹簧朝向参考按已核对区域拆分画布网格，打印份数不变。步骤突出采用阅读用的抬高动画，不能用于判断安装方向、间隙或碰撞。

第二期原设计中的整套精确爆炸合拢、开盖/抽拉运动、独立实体接合仍未完成。后续需为两套基准建立实体映射、定位面/轴、刚体变换及对应手册截图证据，再逐族开放。现有功能不宣称实物装配验证。

## 本地数据与资源预算

按需读取本机完整二进制 STL，不上传文件，不抽样丢三角形，不修改源文件。每文件上限40 MiB / 80万面，整套上限300万显示三角形；同一文件的多份显示共享几何缓存。最多并发读取两个文件，切换型号和离开页面取消加载并释放几何与材质。

S3 1F 示例13文件、15份、2,277,405个显示三角形；S3 2F 示例11文件、11份、1,442,364个显示三角形。文件修订号使用纳秒修改时间字符串，避免 JavaScript 数值精度丢失。

## 验证

- 51项 Python 检查通过：现有32项、9项装配/文件格式、7项子装配与3项可选截面回归检查。
- Node STL解析测试通过：完整三角形、毫米尺寸、远原点居中、有限法向量、损坏数据拒绝。
- HTTP核对：返回的STL与本机原文件SHA-256相同；旧修订号、未知文件拒绝；POST继续要求本机会话令牌。
- 浏览器核对：两型号加载、零件标签和清单选中、聚焦、分解间距、步骤切换、自动播放与暂停、快速切换型号、组合搭建入口、PDF页码定位；1440与390宽度无横向溢出。
- 无WebGL时的文字步骤回退已实现；未模拟GPU设备丢失。移动端只验证了窄屏布局，未做真实手机GPU性能测试。
