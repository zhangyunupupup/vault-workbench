# 组合搭建：数据依据与检查范围

核对日期：2026-10-25，资料版本：用户本地261020。

## 尺寸

官网页面加载的尺寸表提供 S/M/L/XL 宽度164.8/254/329.6/418.8 mm、深度156.1 + (编号−3)×42 mm，以及翻盖箱高度71/99.5/195.5 mm。来源：[官网](https://www.ussadesign.com/pages/vault)所引用的 `vault-family-chooser-print-math.js`。

本地抽屉外壳测量：S3 的打印轴包围盒为164.8×57.01×146.1 mm，S5为164.8×57.01×230.1 mm；2F、4F对应高度105.01、201.01 mm。S系列宽度和深度方向明确，L系列部分文件旋转了45度，不能直接使用打印轴包围盒。官网抽屉名义高度51.5/99.5/195.5 mm比本地外壳高度小5.51 mm，因此布局抽屉采用本地外壳高度48×F+9.01 mm，整体深度使用官网参考值包含前部余量。

这是版本差异下的参考包络，不是完成嵌合的精确装配几何。翻盖箱、顶盖高度及旋转摆放的零件未建立完整装配变换。外部附件、凸起、嵌合重叠和开合空间均不在第一期包络中；不依据这些数值计算打印机适配或负载。

## 叠放

本地《01_Instructions Manual.pdf》第8页明确支持同宽同深模块、抽屉与翻盖箱混搭，以及S+S对应L、S+M对应XL。第一期只检查单个完整支撑面；跨两个箱体的桥接不开放。

- 参考包络相交、低于地面、悬空或底面未完全支撑：红色，禁止组合导出。
- 同尺寸参考包络接触：黄色，说明手册依据，同时要求核对实际嵌合高度与连接扣。
- 不同宽深、上方遮挡翻盖或外部配件：黄色列明未检查项目。
- 落地且未相交：绿色，仅表示列明的参考包络检查通过。

误差容限0.05 mm；场景限制60个模块，坐标范围±10000 mm。X为宽度、Y为深度、Z为离地高度；所有数值输入与三维显示使用相同约定。

## 配色与打印

色板提取自 [Bambu Studio 官方色号文件](https://github.com/bambulab/BambuStudio/blob/master/resources/profiles/BBL/filament/filaments_color_codes.json)，固定保存30个 PLA Basic 单色条目，含中文名、色号和 HEX。颜色仅用于显示和任务分组，材料仍沿用模型库要求，TPU不会变成PLA。

按外壳/顶盖、内抽/分隔、前面板、机构/配件设置颜色；一份STL只有一个颜色，文件内配对零件不拆分。任务聚合键为文件ID、材料、HEX。同颜色相同文件累加份数，不同颜色单独建立目录，原始字节不变。

## 依赖

Three.js 0.160.1 与同版本 OrbitControls 来自 npm 官方 three 包，通过 unpkg 下载。本地保存在 `web/assets/vendor`，MIT许可见同目录 `THREE-LICENSE.txt`；仅将 OrbitControls 的裸模块导入改为本地相对路径。运行时不访问 CDN。

## 验证

32项自动测试覆盖旧配方与导出，以及参考包络边界、负高度、悬空、未知接口、恶意导入、颜色分组、五金数量和文件哈希。浏览器已验证颜色变更、复制、叠放提示、重叠阻止导出、撤销重做、JSON下载与恢复、实际拖动吸附。实际双S3导出15个颜色任务、30次整份打印，包内路径无重复且逐项哈希一致。

390 px与1440 px视口布局已检查，页面无横向溢出；未使用真实手机测试触摸手势。WebGL失败时保留列表、位置输入和导出。爆炸图、精确安装动画和免Python便携包属于后续阶段。
