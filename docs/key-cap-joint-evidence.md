## 坐标与接合面

沿用解析器：各文件 X/Y 包围盒中心归零、源 Z 最低点归零，再把源 `[x,y,z]` 映射为显示 `[x,z,-y]`，单位为毫米。

- 旋钮高度为 33.41703558 mm；手柄顶部作为接触面。
- 盖的内腔底面距源最低点 2 mm，实测平面三角形面积大于 200 mm²。
- 盖绕显示 X 轴旋转 180°，使开口朝向旋钮；中心线对齐，不加横向补偿。
- 盖的显示位置为 `[0,35.41703558,0]`，旋钮保持 `[0,0,0]`。翻转后盖内底面高度为 `35.41703558−2 = 33.41703558`。
- 拆开查看沿显示 +Y 方向移动盖，最大 70 mm。该距离用于观察，不是压装行程或整箱机构运动。

## 可复现检查

可选开发环境安装 `numpy` 和 `shapely` 后，在仓库根目录运行：

```powershell
python scripts/verify_key_cap.py --root "D:\你的VAULT模型库"
```

工作台运行不依赖这两个包。脚本只读取模型，输出数值与哈希，不导出几何。

用真实完整三角形做水平截面；交线坐标取至 0.0001 mm，采用奇偶规则保留孔腔。重叠高度内每隔 0.05 mm 采样，共194层：

## 回归验证

44项 Python 测试通过，包括哈希不匹配/缺件禁用子装配、真实接合面与整套未验证状态。Node 使用实际显示代码检查合拢接触面、展开中间位置、隐藏其他零件以及返回整套后清除旋转与恢复位置。

Node 控制器测试另行验证双向播放、暂停/继续方向、滑块中断、减少动态效果以及切换模式。

浏览器核对两件显示、合拢/拆开端点、滑块、清单联动、返回整套及翻盖箱禁用入口。390宽度无横向溢出，标签边缘已修正。界面支持动画播放、暂停/继续，并在减少动态效果设置下直接到达端点。
