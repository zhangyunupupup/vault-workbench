# S1F 前面板、标准旋钮与盖

核对日期：2026-10-26。此子装配仅在已支持的 S3 1F 标准抽屉配方中开放，不扩展其他型号。

## 来源与定位

官方 `02_Drawer Assembly.pdf` 第1页展示：旋钮由面板背面穿入，盖从正面安装。第2页另行安装左右弹簧；本次三件视图不包含弹簧，也不展示完整锁定机构。

新增核对文件 `S1F (Turn On Supports).stl`，SHA-256：

`7099f6d50adb8bfb6b714799820556fbdc3c9c546e139bb18c46c02f24587709`

旋钮与盖的版本及定位沿用[两件子装配记录](key-cap-joint-evidence.md)。三件视图需要三个文件全部符合哈希；前面板哈希不匹配时，仅保留两件视图；配方所需文件缺失时仍按原规则提示缺件。浏览器核对所有可选子装配涉及的下载字节，切换子装配不再请求模型。

各文件先按 X/Y 包围盒中心归零，源 Z 最低点归零，再映射为显示坐标 `[x,z,-y]`，单位 mm。测得的主要平面如下，数值为平面三角形面积加权高度：

| 接合面 | 归一化高度 mm | 平面面积 mm² |
| --- | ---: | ---: |
| 面板内侧台阶 | 2.400009 | 527.8054 |
| 旋钮挡肩 | 10.800581 | 395.6899 |
| 面板外表面 | 10.000015 | 3637.5985 |
| 旋钮圆台前端面 | 18.400646 | 460.6152 |

两组对应面的高度差分别为 -8.400571 与 -8.400630 mm。采用旋钮平移 `[0,-8.4006,0]`，与两组基准面的偏差均小于 0.0001 mm。前面板位置与旋转为零，旋钮保持源方向；盖仍绕 X 轴翻转180°，与旋钮一起平移后位置为 `[0,27.01643558,0]`。

盖的最低高度高于面板最高高度，两者轴向包围范围不重叠；旋钮与盖的相对定位没有变化。展示拆开时，面板固定，旋钮沿显示 -Y 最大移动60 mm，盖沿 +Y 最大移动70 mm。这些距离便于阅读，不是安装行程。

## 可复现检查

可选开发环境需要 numpy 与 shapely，工作台本身仍只需 Python 标准库：

```powershell
python scripts/verify_panel_joint.py --root "D:\你的VAULT模型库"
```

完整三角形截面，每隔0.05 mm采样，从0.025到9.975 mm，共200层。交线坐标取至0.0001 mm，奇偶规则保留孔腔。检查以下三种状态：

| 旋钮额外轴向偏移 | 最大相交面积 mm² | 采样相交体积 mm³ | 空截面数 |
| --- | ---: | ---: | ---: |
| 0 mm | 0 | 0 | 0 |
| -1 mm | 24.9800 | 15.1205 | 0 |
| +1 mm | 61.5967 | 93.0031 | 0 |

本检查支持所选合拢位置，**不证明连续无碰撞，也不验证插入过程、卡扣变形、打印公差或实物压装**。动画是分解关系插值，实际按手册先装旋钮、后装盖。

## 实现与验证边界

- `joint` 保留旧两件描述，新增 `joints` 返回当前已核对的可选子装配；整套 `precision_ready` 继续为 false。
- 前端选择器切换时停止动画、清除选中、恢复展开位置；选择视图以外的零件返回整套分解视图。
- 46项 Python 测试通过，包括新三件定位、两件数据不受修改、哈希不匹配独立降级。
- Node 控制器检查覆盖播放中切换子装配、清单退出、暂停/继续、无可用子装配和画布失效回退。
- 弹簧 STL 包含左右两件，需要拆分实体、分别核对台阶与旋钮关系；后续核对通过前保持原打印排布。

浏览器已验证：三件合拢与展开、播放中切换两件、整套零件与步骤恢复、翻盖箱禁用子装配入口；390与1440宽度布局，窄屏无横向溢出。控制台未发现错误。
