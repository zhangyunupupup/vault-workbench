# 组合搭建真实模型预览

2026-10-28用户要求提高组合搭建示意图的还原度。沿用已确认方案中的本地真实网格、已核对家族与网格预算边界，先将第二期两套基准的参考定位复用于组合画布。

## 实施范围

- S3 1F标准单抽屉、S3 2F标准整盖翻盖箱读取本机原始STL，文件版本与完整目录一致才显示真实网格；其他型号/选配保持带说明的简化外形。
- 保留坐标、拖动、复制、叠放、配色、撤销重做、方案与导出格式。按外壳后下左角锚定，转换两个画布的深度方向，不用拉伸网格去凑参考包络。
- 不改变包络与碰撞规则；真实网格的突出件、开合空间及实际嵌合仍未纳入布局检查。弹簧形变与接触限制沿用装配页，备用连接扣不摆在安装位。
- 同配置复制箱体共用几何、各自材质。最多缓存2套配置、500万面，场景最多显示600万面，选中箱体优先。超预算、未支持或读取失败时回退简化；独立开关与重新读取按钮允许控制加载。
- 离开搭建页、切换模型库或重扫时取消旧加载并释放缓存。手机静态演示不获取真实模型。
- 加入塑料材质、色调映射与落地阴影，保持现有画布配色。

## 验收

核对17/16个真实实体的完整加载、版本校验、朝向与锚点、重复实例几何共享但颜色独立、移动后位置、缓存释放、选中优先、取消、异常回退。用浏览器检查两套实库外观、配色与布局操作，截图记录实际效果；原有导出与装配回归继续运行。

完成：两套实际文件的33个实体已核对刚体朝向和前左标签位置，浏览器确认真实外观与简化回退、配色、坐标、复制、预算、撤销及390/1440像素布局；原方案已备份并恢复。结果与边界见[真实模型验收](builder-detail-evidence.md)。
