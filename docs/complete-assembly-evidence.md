# 两套基准的完整装配演示

核对日期：2026-10-27。完成已确认第二期的S3 1F标准单抽屉、S3 2F标准整盖翻盖箱打印件流程。这里的“完整”指当前配方中的全部打印文件及实体已纳入步骤和参考定位，**不表示其他型号已验证，也不表示实物装配、连续碰撞、锁定预载或承载认证**。

## 覆盖范围

| 标准示例 | 文件引用 | 整份打印次数 | 安装实体 |
| --- | ---: | ---: | ---: |
| S3 1F抽屉，标签、网格顶盖、1个连接扣 | 13 | 14 | 17 |
| S3 2F标准整盖翻盖箱，标签 | 11 | 11 | 16 |

抽屉包含外壳、内抽、面板、旋钮、盖、两弹簧、一个孔盖、两内轨、两外轨、两限位块、标签、网格顶盖及连接扣。无标签时改为两个孔盖；可选网格顶盖和连接扣按配方增减。连接扣只有一个底部安装位，多选的其他扣明确作为备用件在旁边展示。

翻盖箱包含箱体、顶盖、面板、锁座、内扣、外扣、四根锁销、两下铰链、一上铰链、两根轴及标签。锁销、铰链、轴和弹簧等组合文件按完整三角形连通体拆分，仍按原整份文件打印。

螺栓由步骤五金清单说明，不伪造为用户模型库中的打印文件。安装顺序来源为 `02_Drawer Assembly.pdf` 第1–8页、`03_Sustainers Assembly.pdf` 第1–6页，网格顶盖类型另见 `01_Instructions Manual.pdf` 第10页。

## 修正的配方数量

S1F标签槽覆盖一侧螺丝孔。将标签与该孔盖同时放入，采样相交体积约96.4 mm³，属于重复装件，不能当作卡扣过盈。改为有标签时1个孔盖、无标签时2个，原STL不变。

S1F面板与内抽对应的是两处螺丝孔，使用2颗M4×14。总说明第18页的宽箱示例有4颗，不能直接套给S1F。S3 2F翻盖箱面板的四处孔则与原4颗M4×20数量一致；锁座4颗M4×14、上铰链4颗M4×14、下铰链8颗M4×10保持原数量。打印孔径、螺栓长度和拧紧仍需实物复核。

## 接合依据

抽屉主体和面板三件沿用[主体记录](drawer-body-evidence.md)、[带面板记录](drawer-facade-evidence.md)。限位块根据外壳两侧胶囊孔定位，其参考中心深度27.4496、高度18.4991 mm；孔盖与面板孔心对应；标签平面位于面板标签槽内，避免与孔盖叠装。

网格顶盖先撤销打印时的45°倾斜，再绕竖直轴转180°。参考原点 `[0,71.93436,48.16]`，其底部平面/凸台分别对应外壳上部两层接触面。七个代表截面用于检查方向和高度。源顶盖含15条非流形边，部分完整材料截面无法闭合，因此**未给出整块顶盖的碰撞清空结论**；前端保留全部原始三角形，未静默修复或删面。

翻盖箱顶盖撤销42.8°打印倾角；两组下铰链四孔与箱体两组孔位对应，上铰链四孔与顶盖孔位对应。参考转轴为 `[任意X,-7.5,84.8]`，下铰链/上铰链截面孔心的轴线偏差约0.001 mm量级。锁座四孔对应面板四孔，锁内扣的两侧耳孔连接锁座，中央轴孔连接外扣，不能把这两根轴反接。

详细矩阵和平移均保存在目录中。参考值在数字几何间隙内选取，不是官方标注尺寸或唯一安装位置。

## 弹性与接触的界限

- 弹簧：仅对弹性臂做沿源X的压缩形状示意，安装孔附近保持原形；最大示意位移4.1 mm，不是实测预压量、有限元结果或材料建议。形变只在画布副本上进行。
- 开口锁销：保留源文件的自由形状，以孔轴定位；压入后的实际形变、摩擦和预紧未计算。
- 限位块、连接扣及部分铰链接触处仍有局部数字相交。记录相交值，不把它们默认为零，也不据此断言官方设计过盈或装配强度。
- 锁扣初始向外保留7°的未扣合参考姿态，再翻转75°；顶盖展示0–110°。过大的锁扣翻转会与内扣相交，因此不开放该范围。没有模拟扣紧预载。
- 抽屉展示0–50 mm；不宣称最大限位行程。安装与爆炸动画是关系插值，不是经连续碰撞验证的完整装入路径。

整套 `precision_ready` 保持false；`coverage_complete` 仅表示所选打印件和步骤映射已覆盖。完整视图状态为 `reference_assembly`，与此前局部数字几何检查的状态区分。

## 可复现采样

开发环境需可选numpy/shapely；工作台运行仍只需Python标准库。

```powershell
python scripts/verify_compositions.py --kind drawer --root "D:\你的VAULT模型库"
python scripts/verify_compositions.py --kind sustainer --root "D:\你的VAULT模型库"
```

按宽X方向每0.5 mm取截面，两套各330个平面，抽拉/开盖各检查51个进度。抽屉采样网格避开内抽底板恰好位于0.25 mm网格的顶点平面，首平面-82.237 mm；翻盖箱首平面-82.25 mm。未闭合截面会报错，不能当作空隙。网格顶盖作为明确未认证的例外另列，不参与整块材料清空结论。

数值结果按完整参考目录重新运行并记录；局部接触不因动画打开而被省略。翻盖箱将铰链转轴深度故意错位1 mm的对照可检出约103.16 mm³相交，支持检测流程能发现错误轴线。

当前已知接触包括弹簧与面板、限位块与外壳、连接扣与外壳、开口销与轴孔以及顶盖与下铰链。原始刚体配合、弹性自由形状和形变示意混合存在，**不能把整套结果概括为“零碰撞”**。

完整数值见[抽屉采样结果](complete-drawer-sampling.json)与[翻盖箱采样结果](complete-case-sampling.json)。典型静态相交体积：连接扣/外壳约27.85 mm³，左右限位块/外壳约18.97/18.76 mm³，左右弹簧/面板约5.24/5.15 mm³；两大锁销/内扣各约29.84 mm³，两小锁销/锁座各约16.56 mm³，顶盖/两下铰链各约1.34 mm³。上述是数字相交量，不能当作实物预压或官方设计过盈量。
