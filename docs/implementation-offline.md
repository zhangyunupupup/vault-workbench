# 第三期：离线发行与手机体验

2026-10-28继续已确认的三期方案。本期沿用2026-10-25设计中的第三期，不扩展装配定位家族。

## 实现与验收

1. Windows x64便携ZIP内置官方嵌入式Python、许可、独立搜索路径和当前源码；启动器优先使用包内运行环境。不带用户设置、模型、PDF、导出历史或开发缓存。构建时校验官方SHA-256，生成发行文件校验表。
2. 增加纯静态手机演示，复用原创简化箱体渲染，使用S3 1F抽屉/S3 2F翻盖箱参考包络；不下载或缓存真实STL、官方PDF和本地API。支持添加、选择、坐标、拖动吸附、叠放、配色、复制、删除、撤销恢复与JSON方案文件。
3. 方案沿用version:1。浏览器校验不接受导入的尺寸/清单/路径，只保留白名单配置、坐标、颜色；不支持的型号/改装明确拒绝，不静默改型。桌面导入后继续由现有配方重新解析和核对。
4. 演示以相对资源路径运行，可部署至子目录。独立Service Worker预缓存演示资源，成功后才提示离线就绪；不接管主工作台，不缓存API或用户模型。手机首次联网打开后可离线再访，支持主屏幕入口。
5. 源码、Windows x64便携ZIP、静态演示ZIP、SHA-256和更新说明一起发布。在线演示通过GitHub Pages提供；不开放电脑本地服务的局域网或公网监听。

## 验证顺序

校验配置/导入边界、与桌面方案兼容、包内容白名单和嵌入式Python隔离运行；执行原有回归；浏览器核对桌面与390像素布局、编辑保存恢复和WebGL故障退路；测试离线资源完整性和缓存不读取API。记录实际测试范围，不把桌面窄屏当作真机测试。

## 状态

本期实现与本地验收已完成，发布便携ZIP、静态ZIP与SHA-256；部署脚本只上传经过校验的静态演示至gh-pages。67项Python与4组Node检查通过，浏览器390/1440像素流程、下载与恢复完成。具体边界和截图见[验收记录](offline-evidence.md)，实际发行附件以GitHub Release为准。当前环境没有writing-plans技能，使用本文件记录已确认方案的具体实施步骤。
