# 常用预选

面向初次使用工作台的用户，在配置表单顶部提供六个中文标签。沿用现有橙色选中状态，并显示型号、高度及简要用途。

| 标签 | 型号与组合 | 内部及顶盖 |
| --- | --- | --- |
| 新手首盒 | S3，1F 单抽 | 留空，网格顶盖 |
| 小物分格 | S3，1F 单抽 | 20mm 横纵分隔各1份，网格顶盖 |
| 双抽分类 | M5，2F 外壳内两个1F内抽 | 留空，网格顶盖，自动加入齿条 |
| 翻盖收纳 | S3，2F 标准翻盖箱 | 留空，完整顶盖 |
| 工具分隔 | L5，2F 网格分隔翻盖箱 | 横纵分隔片各1份，完整顶盖 |
| 桌下抽屉 | S3，1F 单抽 | 桌下安装顶盖，连接扣1个 |

点击标签只填入配置，完成零件匹配后由用户加入打印计划。预选以1套为默认，完整重置尺寸、内部布局、标签、提手、齿条、连接扣、底座、轮组、分体盖和数量，避免继承不兼容的旧选项。用户改动配置后取消选中；改回完全相同配置时重新选中。缺少对应箱体型号的模型库禁用相关预选。

配置唯一来源为 `web/assets/presets.json`，由界面读取并由Python测试直接验证；复用既有精确匹配与打包规则。预选资源无法读取时，下方手动配置继续可用。

已验证：19项单元测试通过；浏览器逐一点击6个预选，配置与对应清单均通过检查；自定义取消选中、复杂配件及无效输入重置、没有自动加入计划均通过。验证记录为 `output/review/preset-verification.json`。
