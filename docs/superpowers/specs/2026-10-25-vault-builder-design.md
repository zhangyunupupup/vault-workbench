## 目标与参考

在现有中文工作台中实现用户提供视频所展示的主要能力，保留本地模型库、中文配方和 ZIP 导出流程。

参考：https://xhslink.cn/o/9vnSizcujce 。笔记为迷途醉猫《最强VAULT收纳配置编辑器来了！》。本轮读取了完整功能说明，并观察到视频中的爆炸图、零件标注、颜色分组清单与紧固件采购表；未完成逐帧查看，交互细节须在实施时继续核对。参考行为与流程，界面及实现独立编写。

## 已有基础与差距

已有：型号配置、六个预选、官网系列图片、单文件 STL 预览、配方精确匹配、支撑提示、五金汇总、CSV 和 ZIP 导出。

待新增：多箱体空间布局与保存、可视化叠放检查、配色分配、按颜色分别统计与打包、零件装配变换、爆炸与分步装配、无需 Python 安装的 Windows 发行包。

现有 STL 包围盒是打印坐标下的尺寸，不能直接代替装配尺寸；一份 STL 可能包含成对零件。几何连通体只能辅助识别，不作为唯一装配依据。

## 实现路线比较

1. 推荐：分三期扩展当前项目，每期提供可运行结果与 GitHub Release，逐步核对装配数据。
2. 一次重写成完整编辑器：改动范围大，现有打包和配方更容易出现回归，首次交付更晚。
3. 只做外观相似的演示：可快速展示搭建效果，但不能满足真实选型、校验和打印需求，不推荐。

## 第一期：组合搭建、配色与导出

新增「组合搭建」页面。左侧选择现有已核实的套件，中央操作三维场景，右侧编辑当前箱体；底部显示总清单、五金和校验结果。

- 添加、选择、拖动、网格吸附、复制、删除箱体；旋转和缩放视角，适配触摸操作。
- 支持参数输入定位，避免必须精细拖动；提供撤销和重做。
- 保存布局至本地，支持带版本号的 JSON 导入导出；导入时验证型号、数量、坐标和文件引用，不能信任导入的路径或预计算清单。
- 提供碰撞、悬空和已核实接口的叠放检查：红色表示不通过并给出原因，绿色仅表示已列明的几何及接口检查通过；规则未知显示待核对，不代表承载认证。
- 从官方资料和本地几何建立装配尺寸与接口表，逐条记录依据。未核实型号可继续在原有模型库补打，不进入可装配搭建列表。
- 箱体、内抽、面板与配件可分组配色，支持自定义颜色；拓竹 PLA 色号仅在官方来源核实后录入，注明屏幕色与实物色可能有差异。
- 配色绑定到零件与整份文件打印任务。同一 STL 若含多件，不伪装为可以逐件单独配色；提示整份文件统一颜色。
- 按「文件标识 + 材料 + 颜色」聚合数量。同文件不同颜色分别保留任务和包内目录；保留原文件名及 SHA-256。
- 清单列出颜色、材料、整份打印份数、支撑状态、来源；未明确要求支撑的文件仍显示待切片检查。
- 五金汇总沿用现有依据与核对状态；采购余量作为明确的可选项，不混入实际用量。

第一期仅对经过核对的箱体外形显示装配预览；不把示意轮廓包装成精确内部装配。

## 第二期：爆炸图和安装步骤

- 为已验证套件建立零件局部坐标、装配变换、名称、步骤、五金与手册页码。
- 模型点击高亮，名称与中文零件清单互相定位；爆炸程度滑杆与视角复位。
- 分步播放、暂停、上一步、下一步；每步突出当前安装零件及紧固件。
- 从 S3 1F 抽屉和 S3 2F 翻盖箱开始验证，按结构家族逐步扩展。只有同族变换与依赖验证通过才开放其他规格。
- 对未知位置、缺少配件或不支持的版本明确禁用精确装配动画，并保留官方图和手册入口。
- 不根据零件名称猜螺丝孔位置，不将 STL 原始打印摆放位置直接用于装配动画。

## 第三期：离线发行与手机体验

- WebGL 渲染依赖随项目本地保存，记录版本及许可；离线使用不请求 CDN。
- 发布 Windows 便携版，包含运行环境，解压启动无需另行安装 Python。保留现有源码版。
- 提供原创简化体验单元，未连接模型库时可体验布局和配色；真实 STL 导出仍需用户本地模型库。
- 手机先提供可离线运行的演示、布局和方案文件操作；桌面端加载方案后导出本地 STL。手机不能直接读取电脑磁盘，跨设备文件访问另行设计，不自动开放现有本地服务至公网或局域网。
- GitHub 发布代码、依赖许可和发行包；保持不上传用户 STL 模型库及官方 PDF。

## 架构与数据流

保留 Python 配方、索引和导出模块。前端场景、布局状态、配色、装配步骤分别独立模块；新增场景文件与装配目录具有版本字段。

布局箱体引用配置与实例 ID；配置经过现有服务端配方生成零件。空间位置与装配几何由专用目录管理，不能改变原 STL。颜色任务和配方结果一起进入服务端聚合，导出前重新验证。导出保持临时文件、源文件变化检查与原子完成机制。

几何按需加载与缓存，设置场景和网格预算；超出时显示简化外形，避免一次读取整个模型库。无 WebGL 或资源加载失败时保留原有表单、图片和打包流程。
