## 为什么限制合拢

试探性参考位置使卡口朝向两侧螺丝柱、平整面朝向背面外侧。它不能当作已验证的安装终点：未变形弹簧在候选位置与旋钮、面板仍有相交。0.05 mm间隔、103层截面得到：

| 未变形候选 | 与旋钮采样相交体积 mm³ | 与面板采样相交体积 mm³ |
| --- | ---: | ---: |
| 左件 | 55.8828 | 3.3583 |
| 右件 | 55.8790 | 3.1027 |

这些数值仅说明候选刚体位置存在相交，**不能证明实际预压量、设计过盈、材料形变或安装后的位置**。因此新视图采用 `orientation_only` 状态，保留40%–100%的安装前间距，隐藏并禁用合拢播放；显示层也独立限制最低间距，不能靠直接调用布局把弹簧放到候选终点。

最近允许位置下，两件弹簧最靠前的参考坐标中的Z高度为 -18.249571 mm，仍在旋钮后端 -8.4006 mm 之外；参考视图中没有用相交网格冒充完成压装。40%只是阅读距离，不是40%的实际安装行程。左右标签按面板正面左右定义，背面视角会左右反向。

查看参考数据与采样结果，可在有 numpy/shapely 的开发环境运行：

```powershell
python scripts/inspect_spring_orientation.py --root "D:\你的VAULT模型库"
```

## 截面检查修正与复核

本轮发现两个验证脚本问题：切面恰好经过顶点时，闭合轮廓可能断开；未先处理线段交点时，局部截面可能错误为空。

现在先避开精确顶点平面1e-6 mm，再对交线做节点化，之后多边形化并保留孔腔。若未闭合交线总长超过0.005 mm，检查直接报错，不将结果当作空隙。交线坐标仍取至0.0001 mm。

回归例：前面板 z=0.5 mm 的孔腔不再被错误填满；弹簧 z=5 mm 的有效截面不再丢失。重新执行两件194层与三件200层验证，目标位置及错位对照的结果均与原记录一致。修正未改变源模型或工作台的打印输出。

## 验证

51项 Python 检查全部通过，包含3项需要可选 numpy/shapely 的截面回归检查。Node 检查覆盖完整分件、坏区域/面数拒绝、安装前间距强制限制、参考视图禁用播放，以及切换回两件/三件/整套后恢复原网格。
